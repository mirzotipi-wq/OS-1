# OS-1 vs macOS Sequoia 15.x Interaction & Usability Comparison Matrix (Phase 12)

This document records the exact behavioral mapping between the documented **macOS Sequoia 15.x** reference and **OS-1** (KDE Plasma 5.27 / KWin Wayland on Linux `7.4.0-rc3-os1`), including honest platform differences where Linux/X11/Wayland conventions differ.

| Interaction Area | macOS Sequoia 15.x Reference | OS-1 Implementation | Verification | Honest Platform Notes |
|---|---|---|---|---|
| **Window Controls** | Left-aligned traffic lights (Close, Minimize, Maximize/Zoom) | `OS1Sequoia` Aurorae theme (`ButtonsOnLeft=XIA`, `ButtonsOnRight=`) | `kwinrc` + QEMU screenshot | CSD/GTK apps (e.g. Firefox) use their own headerbars unless GTK decoration layout is also configured |
| **Top Menu Bar** | 28px translucent top bar: system menu, global app menu, status icons, date/time | Plasma top panel (`height=28`): `os1-logo` Kickoff, `org.kde.plasma.appmenu`, `systemtray`, `digitalclock` (`ddd MMM d`) | `qemu-wayland-test.py` + screenshot | Global menu works natively for Qt/KDE apps; Electron/Wayland-native apps without DBusMenu show in-window menus |
| **Dock** | Centered floating glass pill, pinned apps, running indicators, Trash | Plasma centered floating bottom panel (`floating=true`): `org.kde.plasma.icontasks` + `org.kde.plasma.trash` | `qemu-wayland-test.py` + screenshot | Hover magnification uses Plasma's icon task manager hover feedback rather than macOS parabolic wave |
| **Spotlight Search** | `Cmd+Space` global search (apps, files, math, conversions) | `Meta+Space` -> KRunner (`kglobalshortcutsrc`, `krunnerrc` with local runners & web search disabled by default) | `kglobalshortcutsrc` + `krunnerrc` | Uses `Meta` (Super) key instead of macOS `Cmd` to avoid breaking Linux/POSIX terminal `Ctrl+C`/`Ctrl+V` muscle memory |
| **Mission Control & Spaces** | `Ctrl+Up` / 3-finger swipe up; `Ctrl+Left/Right` between Spaces | `Meta+Up` -> KWin Overview (`overviewEnabled=true`); `Meta+Left/Right` across 2+ virtual desktops | `kwinrc` + `kglobalshortcutsrc` | Native KWin Wayland Overview + Slide animation |
| **Screenshots** | `Cmd+Shift+3` (full), `Cmd+Shift+4` (region) | `Meta+Shift+3` / `Meta+Shift+4` -> `kde-spectacle` | `kglobalshortcutsrc` | Saves to `~/Pictures` via Spectacle |
| **File Manager (Finder-class)** | Sidebar Places, breadcrumbs, previews, tabs, Trash, double-click open | Dolphin (`/etc/xdg/dolphinrc`, `SingleClick=false`, `kio-extras` previews, XDG Trash) | `fs-operations-test.py` in QEMU | Verified copy, move, rename, Trash+restore, symlinks, Unicode/emoji, 16 MiB SHA-256, `EACCES` |
| **Appearance Switching** | Light / Dark mode toggle in System Settings | `os1-appearance light|dark` + System Settings -> Appearance (`OS1Light`, `OS1Dark`, `OS1Horizon` light/dark wallpapers) | `qemu-wayland-test.py` Light & Dark screenshots | Instant live theme + wallpaper switching |
| **Accessibility** | Reduce Motion, Reduce Transparency | `os1-accessibility reduced-motion on|off`, `os1-accessibility reduced-transparency on|off` | `qemu-wayland-test.py` | Persisted in `kdeglobals` (`AnimationDurationFactor=0`) and `kwinrc` (`blurEnabled=false`) |
